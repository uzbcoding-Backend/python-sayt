## ✨ What's inside?

This repository contains **two related learning experiences**.

| Project | Language | What you'll find |
|:--|:--|:--|
| [Python learning website](./index.html) | 🇺🇿 Uzbek | Python fundamentals, exercises, projects, blog-style sections, and learning resources |
| [Python Pro Hub](./python-pro-hub/) | 🇬🇧 English | Python learning pages, an in-browser Python runner, developer tools, JavaScript mini games, and portfolio/about pages |

### 🧪 Python Pro Hub features

- **In-browser Python execution:** try Python code directly in the browser through **Pyodide**, loaded from a CDN.
- **Developer utilities:** a dedicated [Dev Tools](./python-pro-hub/tools.html) page.
- **Mini games:** explore the [Games](./python-pro-hub/games.html) page.
- **Separate Python learning area:** [Python](./python-pro-hub/python.html).
- **Responsive design:** dark, blue, and yellow visual theme.

> **Note:** The Python runner needs an internet connection to load Pyodide. Some browser restrictions may affect execution when opening HTML files directly.

## 🚀 Try it locally

No package manager is needed to explore the static pages.

1. Click **Code → Download ZIP** on this repository or clone it:
   ```bash
   git clone https://github.com/uzbcoding-Backend/python-sayt.git
   ```
2. Open `index.html` to explore the Uzbek learning website.
3. Open `python-pro-hub/index.html` to explore the English developer hub.
4. For a consistent local web-server experience, from the repository folder run:
   ```bash
   python -m http.server 8000
   ```
5. Visit `http://localhost:8000/` for the main site or `http://localhost:8000/python-pro-hub/` for Python Pro Hub.
