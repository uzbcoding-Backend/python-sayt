# Python Pro Hub

A 15-file GitHub Pages project that mixes:

- Python learning with an in-browser runner powered by Pyodide
- Developer utilities
- Mini JavaScript games
- Portfolio and About pages
- Responsive black / blue / yellow UI

## Run locally

Open `index.html` in a browser. Most features work directly. The Python runner needs internet access because Pyodide is loaded from a CDN.

## Deploy with GitHub Pages

This project is stored in the `python-pro-hub` folder of the `python-sayt` repository.

## Customize

Edit `portfolio.html` and `about.html` with your real projects, username and links.
